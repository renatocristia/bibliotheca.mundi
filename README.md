📚 Bibliotheca Mundi

Aplicación web para gestión de biblioteca desarrollada con JavaScript avanzado.

👉 [Ver aplicación](https://renatocristia.github.io/bibliotheca.mundi/)

Características
- Formularios con validación avanzada (JS + HTML5)
- Manipulación dinámica del DOM
- Gestión de datos con arreglos y objetos
- Prevención de XSS y sanitización de entradas
- Funciones modulares y reutilizables
- Apoyo con Inteligencia Artificial (ChatGPT/Copilot)
